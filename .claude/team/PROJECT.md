# پروژه: ربات احراز هویت دانشجویان برای گروه تلگرام دانشگاه

- وضعیت: نسخه‌ی 0.1.0 نوشته شده (۲۰۲۶-۱۱-۲۳)؛ هنوز روی تلگرام واقعی آزمایش نشده.
- زبان/محیط: Python 3.13 روی Windows، python-telegram-bot 22.8، SQLite (sqlite3 همگام، یک اتصال).
- هدف: رباتی ادمین در گروه تلگرام که تا دانشجو کد دانشجویی معتبر (از لیست فعال) ثبت نکرده، اجازه‌ی چت ندارد؛ پس از تأیید، username و user_id به آن کد گره می‌خورد.
- فقط کد پرسیده می‌شود؛ نام اختیاری و فقط برای ادمین است.
- مدیریت لیست و کاربران با دستورات ادمین در پیوی ربات.
- فایل‌ها: `README.md` (راه‌اندازی)، `CHANGELOG.md`، `.claude/team/PLAN.md` (طرح)، `DECISIONS.md` (تصمیم‌ها)، `BACKLOG.md` (کارهای باز).
- قراردادها: متن‌های کاربر فارسی و در `bot/texts.py`؛ اعداد نمایشی با `fa_num`؛ داده‌ی واقعی دانشجوها (xlsx/csv/db) در git نمی‌رود؛ تست‌ها بدون شبکه با `python -m pytest -q -p no:anyio`.

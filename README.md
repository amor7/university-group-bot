# ربات احراز هویت دانشجویان (تلگرام)

رباتی فارسی برای گروه تلگرام دانشگاه. تا دانشجو کد دانشجویی‌اش را ثبت نکند، نمی‌تواند در گروه بنویسد. کد باید در لیست دانشجوهای فعال باشد و هر کد فقط به یک حساب تلگرام وصل می‌شود.

**نصب سریع روی سرور اوبونتو:**

```bash
curl -fsSL https://raw.githubusercontent.com/amor7/university-group-bot/main/install.sh | sudo bash
```

## ربات چه می‌کند

- پیام کاربر ثبت‌نکرده را در گروه پاک می‌کند، اجازه‌ی نوشتن را از او می‌گیرد و با یک دکمه به پیوی ربات می‌فرستد.
- در پیوی، دانشجو فقط **کد دانشجویی** را می‌فرستد. اعداد فارسی هم قبول است. اگر کد در لیست باشد و به حساب دیگری وصل نباشد، ثبت انجام می‌شود و دانشجو می‌تواند در گروه بنویسد.
- آیدی عددی و یوزرنیم تلگرام هر دانشجو برای کدش ثبت می‌شود.
- اگر کد در لیست نباشد، پیام «با فلانی یا فلان بخش تماس بگیرید» نشان داده می‌شود. این متن قابل تنظیم است.
- بعد از ۵ تلاش اشتباه، کاربر ۶۰ دقیقه قفل می‌شود و به ادمین‌ها گزارش داده می‌شود.
- **اخراج خودکار اختیاری است و به‌طور پیش‌فرض خاموش است.** یعنی کسی از گروه حذف نمی‌شود؛ ثبت‌نکرده‌ها فقط نمی‌توانند بنویسند. اگر ادمین با `/set_deadline` روشنش کند (بعد از دیدن توضیح و تأیید)، عضوی که تا آن مهلت ثبت نکند از گروه بیرون می‌رود. این بیرون رفتن دائمی نیست و می‌تواند دوباره بیاید.
- **ادمین‌ها** همه‌چیز را در پیوی ربات مدیریت می‌کنند:
  - وارد کردن لیست از فایل Excel یا CSV
  - افزودن و حذف کد
  - خروجی Excel، آمار و بکاپ
  - آزاد کردن یا وصل کردن دستی کد
  - تنظیمات
- هر ثبت و هر قفل به ادمین‌ها یا یک گروه مخصوص گزارش فرستاده می‌شود.
- اختیاری: پشتیبانی از «تأیید درخواست عضویت»؛ ربات بعد از ثبت، درخواست را خودش تأیید می‌کند.
- بکاپ خودکار روزانه، لاگ چرخشی، و اجرای ۲۴ ساعته با روشن شدن خودکار بعد از ریستارت.

## قبل از نصب (برای همه‌ی روش‌ها)

### ۱. ساخت ربات
1. در تلگرام به **[@BotFather](https://t.me/BotFather)** پیام بدهید و `/newbot` را بزنید.
2. اسم و یوزرنیم ربات را بدهید. **توکن** را نگه دارید و به کسی ندهید. شکلش این است: `123456789:AAH...`

### ۲. آماده کردن گروه
1. گروه باید **سوپرگروه** باشد، چون ربات در گروه معمولی نمی‌تواند چت کسی را ببندد. در این حالت‌ها گروه سوپرگروه است:
   - آیدی گروه با `-100` شروع می‌شود.
   - گروه عمومی است.
   - در تنظیمات گروه، **Chat history for new members** روی **Visible** است. اگر نیست، روی Visible بگذارید؛ تلگرام گروه را خودکار سوپرگروه می‌کند.
2. ربات را به گروه اضافه کنید و **ادمین** کنید، با این سه دسترسی:
   - **Delete messages**: حذف پیام‌ها
   - **Ban users**: محدود کردن اعضا
   - **Invite users via link**: برای تأیید درخواست عضویت

### ۳. پیدا کردن آیدی‌ها
- **آیدی عددی خودتان (ادمین اصلی):** به [@userinfobot](https://t.me/userinfobot) پیام بدهید.
- **آیدی گروه:** ربات [@RawDataBot](https://t.me/RawDataBot) را موقتاً به گروه اضافه کنید. عدد جلوی `"chat": {"id":` آیدی گروه است و با `-100` شروع می‌شود. بعد این ربات را از گروه حذف کنید.

این سه چیز را آماده داشته باشید: **توکن**، **آیدی خودتان** و **آیدی گروه**.

## روش ۱: سرور مجازی اوبونتو (پیشنهادی)

روی Ubuntu نسخه‌ی 22.04 یا 24.04، یا Debian 12، با دسترسی root یا sudo.

### نصب با یک دستور
```bash
curl -fsSL https://raw.githubusercontent.com/amor7/university-group-bot/main/install.sh | sudo bash
```
اسکریپت این کارها را انجام می‌دهد:
1. پایتون، venv و git را نصب می‌کند.
2. کد را در `/opt/student-bot` می‌گذارد.
3. کتابخانه‌ها را نصب می‌کند.
4. توکن، آیدی ادمین، آیدی گروه، متن تماس و پروکسی (اختیاری) را **از شما می‌پرسد** و فایل `.env` را می‌سازد.
5. یک **سرویس systemd** می‌سازد. ربات ۲۴ ساعته روشن است، **بعد از ریستارت سرور خودکار بالا می‌آید** و اگر کرش کند ۱۰ ثانیه بعد دوباره روشن می‌شود.
6. دستور مدیریتی `student-bot` را اضافه می‌کند.

ربات با کاربر سیستمی جدای `studentbot` اجرا می‌شود و فایل `.env` فقط برای همان کاربر قابل خواندن است.

### مدیریت
```bash
student-bot status
```
| دستور | کار |
|---|---|
| `student-bot status` | وضعیت ربات |
| `student-bot logs` | ۱۰۰ خط آخر لاگ (`student-bot logs 500` برای بیشتر) |
| `student-bot follow` | لاگ زنده (خروج با Ctrl+C) |
| `student-bot restart` | ریستارت |
| `student-bot stop` / `start` | خاموش / روشن |
| `student-bot config` | ویرایش `.env` با nano و ریستارت خودکار |
| `student-bot update` | به‌روزرسانی به آخرین نسخه‌ی گیت‌هاب |
| `student-bot backups` | لیست بکاپ‌ها |

### به‌روزرسانی
```bash
student-bot update
```
یا همان دستور نصب را دوباره بزنید. فایل `.env`، دیتابیس و بکاپ‌ها دست نمی‌خورند.

### حذف کامل
```bash
sudo systemctl disable --now student-bot
```
```bash
sudo rm -rf /etc/systemd/system/student-bot.service /usr/local/bin/student-bot /opt/student-bot
```
> با این دستور دیتابیس و بکاپ‌ها هم پاک می‌شوند. اگر لازم‌شان دارید، قبلش `/opt/student-bot/bot.db` و پوشه‌ی `backups` را کپی کنید.

### نصب دستی (بدون اسکریپت)
```bash
sudo apt install -y python3 python3-venv git
git clone https://github.com/amor7/university-group-bot.git student-bot && cd student-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env
.venv/bin/python -m bot.main
```
برای اجرای دائمی، فایل سرویس را مثل بخش `۵/۶` داخل `install.sh` بسازید.

## روش ۲: ویندوز و ویندوز سرور

روی Windows 10/11 و Windows Server 2016 به بالا.

### ۱. نصب پایتون
پایتون 3.10 یا جدیدتر را از [python.org](https://www.python.org/downloads/) نصب کنید. حتماً تیک **Add python.exe to PATH** را بزنید. یا در PowerShell:
```powershell
winget install -e --id Python.Python.3.12
```

### ۲. دریافت کد
- با git:
  ```powershell
  git clone https://github.com/amor7/university-group-bot.git C:\student-bot
  ```
- یا از صفحه‌ی گیت‌هاب: **Code ← Download ZIP**، و بعد فایل را در `C:\student-bot` باز کنید.

### ۳. نصب و اجرای خودکار با یک دستور
**PowerShell را با Run as administrator باز کنید** و بزنید:
```powershell
cd C:\student-bot
```
```powershell
powershell -ExecutionPolicy Bypass -File .\install_windows.ps1
```
اسکریپت این کارها را انجام می‌دهد:
1. محیط `.venv` را می‌سازد و کتابخانه‌ها را نصب می‌کند.
2. تنظیمات را می‌پرسد و `.env` را می‌سازد. فقط Administrators و SYSTEM اجازه‌ی خواندن این فایل را دارند.
3. یک Task به نام **StudentBot** در Task Scheduler می‌سازد. این Task:
   - **موقع روشن شدن ویندوز اجرا می‌شود**، حتی اگر کسی لاگین نکرده باشد.
   - با حساب SYSTEM اجرا می‌شود.
   - اگر ربات کرش کند، `run_bot.bat` آن را ۱۰ ثانیه بعد دوباره روشن می‌کند. اگر خود Task از کار بیفتد، ویندوز هر دقیقه دوباره امتحانش می‌کند.
4. ربات را همان لحظه روشن می‌کند.

### مدیریت در ویندوز
| کار | دستور (PowerShell با Administrator) |
|---|---|
| دیدن لاگ | `Get-Content C:\student-bot\logs\bot.log -Tail 50 -Wait` (خطاهای شروع، مثل اشتباه در `.env`، در `logs\stdout.log` هستند) |
| خاموش | `Stop-ScheduledTask StudentBot` و بستن پردازش python |
| روشن | `Start-ScheduledTask StudentBot` |
| ویرایش تنظیمات | `notepad C:\student-bot\.env` و بعد اجرای دوباره‌ی اسکریپت نصب |
| به‌روزرسانی | `git pull` و بعد اجرای دوباره‌ی اسکریپت نصب |
| حذف Task | `powershell -ExecutionPolicy Bypass -File .\install_windows.ps1 -Uninstall` |

> **فقط برای امتحان سریع:** بدون نصب Task هم می‌شود ربات را اجرا کرد: `python -m bot.main`، که با بستن پنجره خاموش می‌شود. یا `run_bot.bat`، که اگر ربات کرش کند خودش دوباره روشنش می‌کند.

## روش ۳: Docker

روی هر سروری که Docker و Docker Compose دارد:
```bash
git clone https://github.com/amor7/university-group-bot.git student-bot && cd student-bot
cp .env.example .env && nano .env
docker compose up -d --build
```
- `restart: unless-stopped` باعث می‌شود ربات بعد از ریستارت سرور و بعد از کرش دوباره بالا بیاید.
- دیتابیس و بکاپ‌ها در پوشه‌ی `data/` و لاگ‌ها در `logs/` کنار پروژه می‌مانند. کانتینر مالکیت این پوشه‌ها را خودش درست می‌کند.

| کار | دستور |
|---|---|
| دیدن لاگ | `docker compose logs -f` |
| ریستارت | `docker compose restart` |
| به‌روزرسانی | `git pull && docker compose up -d --build` |

## روش ۴: هاست

ربات یک برنامه‌ی **همیشه‌روشن** است که مدام از تلگرام پیام می‌گیرد (long polling). برای همین:

### ✅ هاست‌های ابری و PaaS که Docker قبول می‌کنند (پیشنهادی)
مثل لیارا، Railway، Render (از نوع Background Worker) یا Fly.io. این پروژه `Dockerfile` دارد و این سرویس‌ها مستقیم از روی مخزن گیت‌هاب می‌سازند و اجرا می‌کنند.

1. مخزن را به سرویس وصل کنید یا با CLI خود سرویس آپلود کنید.
2. نوع برنامه را **Docker** یا **Worker** انتخاب کنید. پورت و دامنه لازم نیست، چون ربات وب‌سرور ندارد.
3. متغیرهای `BOT_TOKEN`، `ADMIN_IDS` و `GROUP_ID` (و در صورت نیاز `DEFAULT_CONTACT` و `PROXY_URL`) را در بخش Environment Variables سرویس وارد کنید.
4. یک **دیسک یا Volume دائمی** روی مسیر `/app/data` وصل کنید. **این مرحله مهم است.** بدون آن، با هر deploy دیتابیس و ثبت‌ها پاک می‌شود.
5. فقط **یک** نسخه (instance) از ربات اجرا کنید. دو نسخه‌ی هم‌زمان با یک توکن با هم تداخل می‌کنند.

### ⚠️ هاست اشتراکی (cPanel / DirectAdmin)
بیشتر هاست‌های اشتراکی برنامه‌های همیشه‌روشن را بعد از مدتی می‌بندند. اگر هاست شما **SSH** و **Python 3.10 به بالا** دارد، این روش ممکن است کار کند، ولی تضمینی نیست:
```bash
cd ~ && git clone https://github.com/amor7/university-group-bot.git student-bot && cd student-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env
bash hosting/keepalive.sh
```
بعد در cPanel، در بخش **Cron Jobs**، یک کار هر ۵ دقیقه اضافه کنید تا اگر ربات بسته شد دوباره روشن شود:
```
*/5 * * * * /bin/bash $HOME/student-bot/hosting/keepalive.sh >/dev/null 2>&1
```
> اگر هاست برنامه را مدام می‌بندد یا SSH ندارد، از سرور مجازی (روش ۱) یا PaaS استفاده کنید. ارزان‌ترین VPS هم برای این ربات کافی است.

## سرور در ایران: پروکسی تلگرام

اگر سرور در ایران است، `api.telegram.org` فیلتر است و ربات وصل نمی‌شود. خطای اتصال یا timeout در لاگ می‌بینید. دو راه دارید:

1. **پیشنهادی:** سرور خارج از ایران بگیرید.
2. یک پروکسی HTTP یا SOCKS5 که به تلگرام دسترسی دارد در `.env` بگذارید:
   ```
   PROXY_URL=socks5://127.0.0.1:1080
   ```
   شکل‌های قابل قبول: `http://host:port`، `socks5://host:port` و `socks5://user:pass@host:port`

   در **Docker**، اگر پروکسی روی خود سرور اجرا می‌شود، به‌جای `127.0.0.1` بنویسید `host.docker.internal`.

## تنظیمات (.env)

اسکریپت‌های نصب این فایل را خودشان می‌سازند. در نصب دستی، `.env.example` را به `.env` کپی کنید. **فایل `.env` را هیچ‌جا منتشر نکنید.**

| متغیر | لازم؟ | توضیح |
|---|---|---|
| `BOT_TOKEN` | بله | توکن BotFather |
| `ADMIN_IDS` | بله | آیدی عددی ادمین‌های اصلی، با کاما جدا، مثل `123456789,987654321`. فقط این‌ها می‌توانند ادمین اضافه یا حذف کنند. هشدارها و گزارش‌ها هم به پیوی این‌ها می‌رود. |
| `GROUP_ID` | بله | آیدی سوپرگروه، مثل `-1001234567890`. بدون آن ربات گروه را کنترل نمی‌کند. |
| `DB_PATH` | نه | مسیر دیتابیس. پیش‌فرض `bot.db` در پوشه‌ی پروژه. |
| `DEFAULT_CONTACT` | نه | متن یا آیدی تماس برای دانشجویی که کدش پیدا نشد، مثل `@edu_office`. بعداً با `/set_contact` هم قابل تغییر است. |
| `PROXY_URL` | نه | پروکسی تلگرام برای سرورهای ایران |

بعد از تغییر `.env` ربات را ریستارت کنید.

## شروع کار بعد از نصب

1. در تلگرام ربات را باز کنید و `/start` و بعد `/help` را بزنید. باید راهنمای ادمین را ببینید.
2. **وارد کردن لیست:** فایل Excel لیست دانشجوها را در پیوی ربات **بفرستید**. ربات پیش‌نمایش نشان می‌دهد؛ دکمه‌ی **«➕ افزودن به لیست»** را بزنید.
   - ستون کد دانشجویی لازم است و ستون نام اختیاری است.
   - ربات ستون‌ها را از روی سطر اول پیدا می‌کند، مثلاً «شماره دانشجویی»، «کد دانشجویی» و «نام و نام خانوادگی». اگر سطر عنوان نباشد، ستون اول کد فرض می‌شود.
   - کد فقط رقم است، بین ۶ تا ۱۵ رقم.
   - برای حفظ صفر اول کدها، ستون کد را در Excel روی قالب **Text** بگذارید.
3. متن تماس را تنظیم کنید:
   ```
   /set_contact اگر کدتان پیدا نشد به @edu_office پیام بدهید.
   ```
4. با یک اکانت دیگر در گروه پیام بدهید. پیام باید پاک شود و دکمه‌ی ثبت بیاید. کد را در پیوی ربات بفرستید تا ثبت شوید.
5. برای اعضای فعلی گروه یک اطلاعیه بگذارید که از طریق ربات ثبت کنند.

📘 **آموزش کامل ادمین** با مثال و سناریوهای رایج در [`docs/admin-guide.html`](docs/admin-guide.html) است. فایل را دانلود کنید و در مرورگر باز کنید.

## دستورات ادمین

همه‌ی دستورها **فقط در پیوی ربات** و فقط برای ادمین‌ها کار می‌کنند. `/help` همین لیست را داخل ربات نشان می‌دهد.

| دستور | کار | مثال |
|---|---|---|
| ارسال فایل | وارد کردن Excel یا CSV؛ پیش‌نمایش و بعد «افزودن» یا «جایگزینی کامل» | — |
| `/add` | افزودن کد؛ چند کد با فاصله یا هر خط «کد نام» | `/add 4001112223 4001112224` |

**افزودن یا جایگزینی؟**
- «➕ افزودن» فقط کد جدید اضافه می‌کند.
- «🔄 جایگزینی کامل» لیست را با فایل عوض می‌کند. کدی که در فایل نباشد حذف می‌شود و صاحبش محدود می‌شود. قبلش بکاپ گرفته می‌شود. این گزینه برای لیست ترم جدید مناسب است.

## روند ثبت دانشجو

1. وارد گروه می‌شود یا پیام می‌دهد. پیامش پاک می‌شود و دکمه‌ی **«🎓 ثبت کد دانشجویی»** را می‌بیند. پیام راهنما ۳ دقیقه بعد پاک می‌شود.
2. دکمه را می‌زند و در پیوی ربات کد دانشجویی‌اش را می‌فرستد.
3. اگر کد در لیست باشد و آزاد باشد، ثبت می‌شود و می‌تواند در گروه بنویسد. به ادمین‌ها گزارش داده می‌شود.
4. پیام مناسب برای هر حالت دیگر:
   - کد پیدا نشد: متن تماس
   - کد با حساب دیگری ثبت شده: راهنمای تماس با پشتیبانی
   - فرمت کد غلط است: مثال درست
   - تلاش‌های اشتباه زیاد: قفل موقت
5. به‌طور پیش‌فرض کسی از گروه بیرون نمی‌رود. فقط اگر ادمین اخراج خودکار را روشن کرده باشد، کسی که تا مهلت ثبت نکند بیرون می‌رود ولی می‌تواند دوباره بیاید.

ادمین‌های گروه و پیام‌هایی که به نام خود گروه یا کانال متصل فرستاده می‌شوند معاف‌اند.

## بکاپ و لاگ

- **بکاپ دیتابیس** در پوشه‌ی `backups/` کنار دیتابیس ذخیره می‌شود. در Docker مسیرش `data/backups/` است.
  - بکاپ گرفته می‌شود: هنگام روشن شدن ربات، هر ۲۴ ساعت، و قبل از «جایگزینی کامل» و `/clear_list`.
  - ۳۰ بکاپ آخر نگه داشته می‌شود.
  - `/backup` در ربات هم فایل بکاپ را برایتان می‌فرستد.
  - **بکاپ‌ها را گاهی بیرون از سرور هم نگه دارید.**
- **بازگردانی بکاپ:** ربات را خاموش کنید، فایل بکاپ را جای `bot.db` بگذارید و دوباره روشن کنید.
- **لاگ:**
  - فایل `logs/bot.log`، چرخشی، ۵ فایل ۵ مگابایتی.
  - در اوبونتو با `student-bot logs` هم دیده می‌شود.
  - در لاگ فقط آیدی‌ها می‌آیند، نه متن پیام‌ها.

## رفع اشکال

| مشکل | راه‌حل |
|---|---|
| `Config error: BOT_TOKEN is not set` | فایل `.env` نیست یا توکن خالی است. |
| `GROUP_ID must be an integer` | فقط عدد آیدی گروه را بنویسید، مثل `GROUP_ID=-1001234567890`. |
| ربات وصل نمی‌شود یا timeout می‌دهد | تلگرام روی سرور فیلتر است. سرور خارج بگیرید یا `PROXY_URL` بگذارید. |
| `Conflict: terminated by other getUpdates request` | ربات با همین توکن جای دیگری هم روشن است. فقط یک نسخه روشن بماند. |
| پیام‌ها پاک نمی‌شوند یا چت کاربر بسته نمی‌شود | ربات ادمین نیست یا دسترسی «Delete messages» و «Ban users» ندارد، یا گروه سوپرگروه نیست. ربات در این حالت به ادمین‌های اصلی هشدار می‌دهد. |
| دستورهای ادمین جواب نمی‌دهند | دستورها فقط در **پیوی** کار می‌کنند. آیدی شما باید در `ADMIN_IDS` باشد یا با `/add_admin` اضافه شده باشید. |
| دانشجو ثبت کرده ولی نمی‌تواند بنویسد | در پیوی ربات دوباره `/start` بزند. اگر بن شده باشد، یکی از ادمین‌های گروه باید دستی بنش را بردارد. |

python -m venv .venv

.venv/bin/python -m pytest -q -p no:anyio

  - `bot/handlers/`: دستورها و رویدادها

## محدودیت‌ها

- **اعضای قدیمی ساکت شناسایی نمی‌شوند.** تلگرام لیست کامل اعضا را به ربات نمی‌دهد. عضوی که هیچ‌وقت پیام ندهد، ثبت‌نکرده باقی می‌ماند. برای همین در گروه اطلاعیه بگذارید.
- **کدهای دانشجویی قابل حدس‌اند.** کدها ترتیبی‌اند و فقط کد پرسیده می‌شود. برای جبران این موارد هست:
  - قفل بعد از تلاش‌های اشتباه
  - گزارش هر ثبت به ادمین‌ها
  - امکان `/unbind` برای حل اعتراض
- فعلاً فقط یک گروه پشتیبانی می‌شود.
- پیش از استفاده‌ی اصلی، ربات را حتماً در یک گروه آزمایشی امتحان کنید.
